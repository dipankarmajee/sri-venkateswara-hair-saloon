# Sri Venkateswara Hair Saloon Website

A high-performance, fully responsive modern web application built with **Next.js 14**, **Tailwind CSS**, and **Framer Motion** for **Sri Venkateswara Hair Saloon** located in Gulmohar Park Colony, Serilingampalle, Hyderabad.

---

## 🌟 Key Features

1. **Live Open / Closed Status Badge**:
   - Accurately computes store status in Indian Standard Time (IST).
   - Shows "SHOP IS OPEN NOW • Closes at 9:30 PM" (or "CURRENTLY CLOSED • Opens at 8:00 AM") with real-time pulsing indicators.

2. **Opening & Closing Timings**:
   - Monday to Friday: `8:00 AM – 9:30 PM`
   - Saturday & Sunday: `7:30 AM – 10:00 PM`
   - Peak rush guide and recommendations for zero-wait visits (11:30 AM – 4:30 PM).

3. **Complete Grooming Services Menu with Categorized Filters**:
   - **Haircuts**: Regular cut, Skin Fade, Taper, Textured Crop, Pompadour, Kids' Haircut, Senior Citizen styling.
   - **Beard & Shave**: Classic Shave, Beard Shaping & Trimming, Sharp Razor Lineup, Royal Shave.
   - **Head Spa & Treatments**: Cooling Mint Head Massage, Anti-Dandruff Therapy, Nourishing Hair Spa, Ammonia-Free Hair Color.
   - **Facials & Clean-Up**: De-Tan Instant Pack, Herbal Fruit Glow, Charcoal Deep Pore Detox, Gold Radiance.
   - **Value Combos**: Daily Smart Combo, Modern Gentleman Combo, Full VIP Grooming.

4. **Style Lookbook**:
   - Detailed visual guides for popular cuts inspired by salon styles (Fade, Textured Crop, Pompadour, Razor Beard Edge, Kids Styling).

5. **Sanitization & Amenities**:
   - ❄️ Chilled Split AC Interior
   - 📺 TV Screen Entertainment
   - 🪒 100% Single-use fresh sanitized blades for every customer
   - 💳 UPI (GPay, PhonePe, Paytm) & Cash payments accepted

6. **Interactive Google Maps & Directions**:
   - Embedded Google Map centered on Gulmohar Park Colony, Serilingampally, Hyderabad (500019).
   - Direct integration with Google Knowledge Graph (`/g/11kj6cj0jt`) and one-click Google Maps turn-by-turn directions.
   - Distance indicators from Lingampally MMTS Station (5 mins) and Nallagandla (6 mins).

7. **Interactive Appointment & Queue Modal**:
   - Instant booking dialog with service selection, preferred day & time slot.
   - One-tap WhatsApp confirmation link and direct phone hotline.

8. **Mobile-First Experience**:
   - Responsive sticky header with navigation drawer.
   - Bottom floating mobile action bar with 1-tap "Call", "WhatsApp", "Book Slot", and "Map Directions".

---

## 🚀 Running the Project

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Or build and start production server
npm run build
npm run start
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.
